# 猫咪续命派对 · 官方下载

这里是《猫咪续命派对》的公开发行仓库，只存放 Windows / macOS 安装包、SHA-256 校验文件与发布说明，不包含游戏源码。

## 下载

请前往 [Releases](https://github.com/LaRysLuo/cat-match-party-releases/releases/latest) 下载最新版本：

- `CatMatchParty-Windows-x86_64.zip`：Windows 10/11 64 位
- `CatMatchParty-macOS-universal.zip`：macOS Intel / Apple Silicon 通用版本
- `SHA256SUMS.txt`：文件完整性校验

游戏主界面的“检查更新”功能也会从这里读取最新版本并下载对应平台的更新包。

## macOS 提示

当前版本未使用 Apple Developer ID 签名和公证。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择允许打开。
